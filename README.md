# 🌸 Jolly Phonics Learning App

子ども向けフォニックス学習Webアプリ（4〜7歳対象）

## 機能概要

### Phase 1 ✅ ホーム・コアデータ
- **花園UI** (`/`) — 7グループ×6音素の花びらナビゲーション
- **42音素データ** — 全音素の完全なデータセット
- **72 Tricky Words** — グループ別段階導入
- **Zustand + localStorage** — 進捗の永続化
- **useAudio フック** — 音声ファイル未存在時のサイレントフォールバック

### Phase 2 ✅ コア学習体験
- **音素レッスン** (`/phoneme/[id]`) — 音声・書き順・例文・ストーリー・アクション
- **SVG書き順アニメーション** — 26文字+ダイグラフのストローク描画
- **進捗画面** (`/progress`) — プロフィール編集・グループ別進捗・スコア一覧

### Phase 3 ✅ ゲーム（基本4種）
- **🎵 Blending** (`/games/blending`) — 音素を聞いて単語を合成（10問/セッション）
- **🧩 Segmenting** (`/games/segmenting`) — 単語を音素に分解（タップ入力）
- **🌟 Tricky Words** (`/games/tricky-words`) — フラッシュカード式の不規則語認識
- **🔤 Letter Match** (`/games/letter-match`) — 音声と文字の対応付け

### Phase 4 ✅ ゲーム（追加4種）
- **🫧 Bubble Pop** (`/games/bubble-pop`) — タイムアタック形式の音素泡割りゲーム
- **🐾 Whack-a-Mole** (`/games/whack-a-mole`) — 3×3グリッドで正しい文字のモグラを叩くゲーム
- **🎣 Word Fishing** (`/games/word-fishing`) — 川を泳ぐ魚の中から正しい単語を釣るゲーム
- **🃏 Memory Match** (`/games/memory-match`) — 文字カードと絵文字カードをペアで揃える神経衰弱

## ゲーム仕様詳細

### 🫧 Bubble Pop
| 項目 | 仕様 |
|------|------|
| 形式 | タイムアタック（30秒） |
| 出題 | 学習済みグループの音素をランダム出題 |
| 操作 | 正しい音素が書かれた泡をタップ |
| スコア | 正解 +10pts・ミスカウントあり |
| 演出 | 正解：パン！と弾けるエフェクト／不正解：ぐにゃと縮むエフェクト |
| 泡数 | 常時 5〜7個を画面上に維持 |

### 🐾 Whack-a-Mole
| 項目 | 仕様 |
|------|------|
| 形式 | 制限時間60秒・ライフ制（3ライフ） |
| 出題 | 学習済みグループの音素をランダム出題 |
| 操作 | 9つの穴から出てくるモグラの中から正しい文字を叩く |
| スコア | 正解 +10pts |
| 難易度 | スコアに応じて出現速度が段階的に上昇 |
| ライフ | 不正解でライフ-1、0になるとゲームオーバー |

### 🎣 Word Fishing
| 項目 | 仕様 |
|------|------|
| 形式 | 10問制（10匹釣りきりでクリア） |
| 出題 | 学習済み音素の例文単語をターゲットに指定 |
| 操作 | 川を泳ぐ魚（5匹同時表示）の中から正しい単語の魚をタップ |
| スコア | 正解 +10pts |
| 演出 | 釣れた魚はバケツに蓄積・コレクション感のある結果表示 |
| 魚 | 色・サイズ・泳ぐ方向・速度がランダムで生成 |

### 🃏 Memory Match
| 項目 | 仕様 |
|------|------|
| 形式 | 全ペア完成クリア、手数とタイムを記録 |
| 出題 | 学習済み音素から難易度に応じた枚数を出題 |
| 操作 | 「文字カード」と「絵文字カード」の対応するペアをめくって揃える |
| 難易度 | Easy: 4×3（12枚）/ Medium: 4×4（16枚）/ Hard: 5×4（20枚） |
| 演出 | カードをめくった瞬間に音素の音声が再生、3Dフリップアニメーション |
| スコア | クリアタイムと手数から自動計算 |

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# プロダクションビルド
npm run build

# Vercelデプロイ
npx vercel --prod
```

## 音声ファイルの追加

```
public/
└── audio/
    ├── phonemes/    ← s.mp3, a.mp3, ai.mp3, oo_short.mp3, oo_long.mp3...
    ├── words/       ← sun.mp3, sat.mp3, sock.mp3...
    └── tricky/      ← the.mp3, said.mp3, was.mp3...
```

音声ファイルが存在しない場合でもアプリは正常動作します（コンソールに警告のみ）。
